# Drill 14: 새의 비행 애니메이션

LEC 16의 프레임 시간과 속도 계산을 이용해 새 열 마리가 화면에서 좌우로 날아갑니다.
새의 높이는 프로그램을 실행할 때마다 각각 무작위로 정해집니다.

## 실행

`pico2d`가 설치된 Python 환경에서 이 폴더를 작업 폴더로 열고 `python main.py`를 실행합니다.
Esc 키 또는 창 닫기 버튼으로 종료합니다.

## 계산 순서

1. 강의의 축척처럼 10픽셀을 0.3m로 정합니다. 따라서 1m는 약 33.33픽셀입니다.
2. 예시 비행 속력은 시속 13km입니다. 새의 실제 비행 속도를 측정한 값이 아니라 화면에서 확인하기 위해 정한 값입니다.
3. 시속을 분속과 초속으로 바꾸고, 1m에 해당하는 픽셀 수를 곱하면 초당 약 120.37픽셀입니다.
4. 이동 거리는 `픽셀/초 × 프레임 시간(초)`으로 계산합니다. 방향이 왼쪽이면 음수로 더합니다.
5. 날갯짓은 14개 자세를 1.2초에 한 번 재생하도록 초당 자세 변경량을 구합니다. 이는 실습용으로 정한 주기이며 이동 속도에서 유도한 값은 아닙니다.
6. 프레임 값은 소수로 누적하고 그림을 자를 때만 정수로 바꿉니다. 화면 끝에서 남은 이동 거리를 반영해 방향을 바꾸고 이미지를 뒤집습니다.

높이는 생성 시 한 번만 무작위로 정해지며, 새끼리 서로 겹칠 수 있습니다.
프레임 시간 계산, 속도 환산과 소수 프레임의 사용은 LEC 16 PDF의 순서를 따릅니다.
새 이미지 분할, 방향 전환, 날갯짓 주기와 무작위 높이는 과제에 맞게 추가한 내용입니다.
